# Virtual-Home-Lab (Windows Server Active Directory)

Goal:
Build an enterprise-style Active Directory environment using Windows Server and Windows 10 Client.

Environment:
- VMWre Workstation 17
- Windows Server 2022
- Windows 10 client
- 16GB RAM host machine

Phases:
1. Virtual environment setup
2. Domain controller deployment
3. Active directory structure
4. Group policy configuration
5. Client setup
